{{ L('Agent 分工', 'Agent split') }}

NurseAgent — {{ L('对状态对象做确定性首筛，比对项目阈值、个人基线、持续性与传感质量标志。八条规则：跌倒、HR/RR/体温偏离（z-score 优先）、低置信度、NLOS、模态冲突、呼吸基线偏离。', 'deterministic first screen over the state object, comparing it with project thresholds, personal baselines, persistence, and sensing-quality flags. Eight rules: fall, HR/RR/temperature deviation (z-score first), low confidence, NLOS, modality conflict, respiratory baseline deviation.') }}

DiagnosisAgent — {{ L('在受限证据图上的虚拟分诊医生，不接收原始数据流。注册工具检索个人基线、传感质量、跨模态仲裁、近期事件与最新状态。', 'a virtual triage doctor over a bounded evidence graph. It never receives raw streams. Registered tools retrieve the personal baseline, sensing quality, cross-modal arbitration, recent events, and the latest state.') }}

ReportAgent — {{ L('把决策转为纵向记忆，使居民提醒、家属通知与临床复核共用同一条证据链。', 'turns decisions into longitudinal memory, so resident prompts, family notifications, and clinician review share one evidence trail.') }}
